Работаем над сетью.
Сторона хоста сделана, доделать внутри контейнера команды.

зайло: /var/lib/zylo/*

Шпаргалка:
sudo ip link add name zylo{quantity} type bridge
sudo ip addr add {IP}/{subIP} dev zylo{quantity}
sudo ip link set dev zylo{quantity} up

sudo ip link add zylo{quantity}-host type veth peer name zylo{quantity}-conn
sudo ip link set zylo{quantity}-conn master zylo{counted}
sudo ip link set zylo{quantity}-host up
sudo ip link add zylo{quantity}-cont type veth peer name zylo{quantity}-peer
sudo ip link set zylo{quantity}-peer master zylo{quantity}

// after starting cont
sudo ip link set zylo{quantity}-cont netns 18794


sudo sysctl -w net.ipv4.ip_forward=1
sudo iptables -t nat -A POSTROUTING -s 10.0.0.0/24 -o eno1 -j MASQUERADE


in cont:
sudo nsenter --target {container PID} --net
ip link set dev zylo{quantity}-cont name eth0
ip link set dev eth0 up
ip addr add eth0_IP/eth0_subIP dev eth0
ip route add default via {bridge IP}

host(zylo{quantity}-host) <--> zylo{quantity}(zylo{quantity}-conn)

zylo{quantity}(zylo{quantity}-peer) <--> zylo{quantity}-cont
